# Transfer Learning 迁移学习

## 定义

迁移学习是将从一个任务学到的知识应用到另一个相关任务的技术。

## 核心思想

```
源任务（大数据）→ 知识 → 目标任务（小数据）
```

## 何时使用

| 条件 | 说明 |
|------|------|
| 输入相同 | 两任务输入类型一致（如都是图像） |
| 源数据更多 | 源任务数据量 > 目标任务 |
| 低层特征可迁移 | 底层特征通常可跨任务共享 |

## 策略

| 数据量 | 策略 |
|--------|------|
| 极少 (< 1K) | 冻结特征提取器，只训练分类头 |
| 少 (1K-10K) | 微调最后几层 |
| 中等 (10K-100K) | 微调更多层 |
| 大 (> 100K) | 从头训练或微调全部 |

## 经典预训练模型

| 模型 | 数据集 | 任务 |
|------|--------|------|
| ImageNet 预训练 | ImageNet 1.2M | 图像分类 |
| CLIP | 400M 图像-文本对 | 多模态 |
| BERT | Books + Wikipedia | NLP |
| GPT | Internet text | 语言模型 |

## 微调技巧

| 技巧 | 说明 |
|------|------|
| 较低学习率 | 通常 1e-4 ~ 1e-5 |
| 早停 | 监控验证集损失 |
| 层衰减 | 越浅层学习率越低 |

## 与 [[Neural Network]] 的关系

迁移学习通过复用预训练网络的权重来实现，是现代深度学习最重要的技术之一。
