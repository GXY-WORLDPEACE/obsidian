# SEO (Search Engine Optimization)

## 概述

通过优化网站内容和结构，提高在Google等搜索引擎中的排名，从而获得免费的有机流量。

## AI工具站的SEO四步法

| 方法 | 说明 | 工具 |
|------|------|------|
| **词找站** | 用关键词在Google搜，看排名靠前的网站 | Google搜索 |
| **站找词** | 找到竞品站，反查它靠哪些关键词拿流量 | Ahrefs, SEMrush |
| **词找词** | 从一个关键词扩展相关词、长尾词、新词 | Google Trends |
| **站找站** | 从一个竞品找到更多同类网站 | - |

## 核心原则

**用户搜索什么，你就做什么**

```
AI background remover → 去背景工具
AI detector → 检测AI内容
AI humanizer → 文章真人化
AI PPT maker → 做PPT工具
```

每个搜索词背后都是一个可产品化的需求。

## 关键词类型

```
短尾词（高搜索量，高竞争）：
  "AI tools", "image editor"
  
长尾词（低搜索量，低竞争，高转化）：
  "AI background remover for product photos"
```

## Google Trends用法

- 调到**最近7天**看Rising飙升词
- 突然冒出来的新词 = 新需求
- https://trends.google.com/trends/

## SEO与AI工具站

```
用户痛点 → 搜索词 → 工具页面 → 变现

Google是入口：
  用户有问题 → Google搜 → 找到你的工具 → 使用 → 付费
```

## 监控竞品sitemap

通过监控大站的sitemap更新，发现新需求：
- CrazyGames等游戏站每天新增很多页面
- 新增URL和页面标题 = 新的搜索需求
