# 半导体投资框架

## 核心观点

### 1. 周期性 vs 结构性

| 类型 | 特征 | 估值方法 |
|------|------|----------|
| **结构性瓶颈** | 技术壁垒高、客户绑定强、供给弹性低 | 成长科技股PE |
| **周期性紧缺** | 供需波动、库存周期、价格战 | 传统周期股PS/PB |

**案例区分**：
- HBM = 结构性（给予更高估值）
- 传统DDR = 周期性（HBM挤出效应可延长周期）
- NAND/SSD = 需求受益但非核心瓶颈

### 2. 寡头竞争逻辑

存储从数十家玩家整合到三家：
- 三星、SK海力士、美光

**CapEx纪律是核心变量**：
- 扩产狂魔 → 全行业亏损
- 默契控供给 → 利润指数级放大

### 3. 经营杠杆

```
重资产、高固定成本（晶圆厂$150-200亿）

ASP每上涨$1 → 几乎100%转化为营业利润

（前提：产能利用率稳定）
```

## 投资指标体系

### 供给侧
- CapEx占营收比例（健康30%，危险>40%）
- 产能扩张速度
- 技术节点进展

### 需求侧
- 云厂商CapEx
- 英伟达GPU出货节奏
- HBM认证进展

### 库存周期
- DIO（库存周转天数）
- 渠道库存
- 补库信号

### 财务信号
- 毛利率扩张速度
- 自由现金流
- 存货减值（可能是利空出尽）

## 估值逻辑对比

```
传统周期股：
  P/B 1-3倍 → 随周期波动

转型中的半导体：
  部分业务用SOTP：HBM给P/E 20-25x，传统给P/B 2-3x

纯AI基础设施：
  对标软件公司估值
```

## 关键风险

1. 云厂商资本开支收缩
2. 技术路线颠覆
3. 地缘政治/出口管制
4. 新进入者扩产
