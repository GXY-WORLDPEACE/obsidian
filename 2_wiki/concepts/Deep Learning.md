# Deep Learning (深度学习)

## 定义

深度学习是[[Machine Learning]]的一个子领域，使用具有多个隐藏层的**人工神经网络**来自动学习数据的层次化表示。

## 核心特征

| 特征 | 说明 |
|------|------|
| **层次化表示** | 从原始数据中自动学习多层次特征 |
| **端到端学习** | 直接从输入到输出，无需手工特征工程 |
| **大规模数据** | 通常需要大量标注数据 |
| **计算密集** | 依赖 GPU/TPU 等高性能计算资源 |

## 发展历程

```timeline
2012: AlexNet - ImageNet 竞赛突破
2014: VGG, GoogLeNet - 网络深度增加
2015: ResNet - 残差连接解决梯度消失
2017: Transformer - Attention 机制革命
2020s: 大规模预训练模型 (GPT, BERT, LLM)
```

## 主要架构类型

1. **MLP (多层感知机)** - 最基础的全连接网络
2. **CNN (卷积神经网络)** - 图像处理
3. **RNN (循环神经网络)** - 序列数据
4. **Transformer** - 注意力机制，NLP 革命
