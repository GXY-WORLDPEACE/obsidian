# I2DL Lecture 1: 课程介绍与深度学习概述

## 摘要

本课程由 TUM 的 Matthias Niessner 教授主讲，系统介绍深度学习的基础理论与实践。课程涵盖人工智能、机器学习到深度学习的层次关系，计算机视觉的演进历史，以及深度学习在各领域的应用现状。

## 核心内容

### 1. AI → ML → DL 的演进

| 层级 | 方法 | 特点 |
|------|------|------|
| **AI** | 规则系统、搜索算法 | 显式编程 |
| **ML** | 线性回归、SVM、决策树 | 数据驱动 |
| **DL** | 神经网络、Transformer、生成模型 | 端到端学习 |

### 2. 计算机视觉历史

- **2012年前**: 传统方法主导，AlexNet 之前 ImageNet top-5 错误率约 25%
- **2012年后**: AlexNet 突破，深度学习时代开启
- **关键节点**: AlexNet(2012) → VGGNet(2014) → ResNet(2015, 超越人类水平)

### 3. 深度学习成功三要素

```
Big Data     → 数据量爆发
Hardware     → GPU 算力提升  
Deep Models  → 模型复杂度增加
```

### 4. 课程结构

| 讲次 | 内容 |
|------|------|
| L1 | 课程介绍、ML/DL 概述 |
| L2 | 机器学习基础、线性回归、最大似然估计 |
| L3 | 神经网络入门、计算图 |
| L4 | 优化与反向传播 |
| L5 | SGD 及变种 |
| L6-8 | 神经网络训练技巧 |
| L9-10 | CNN 及架构 |
| L11-12 | RNN 与 Transformer |
