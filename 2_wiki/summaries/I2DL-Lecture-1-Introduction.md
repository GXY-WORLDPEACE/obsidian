# I2DL Lecture 1: Introduction

## 摘要

本讲为慕尼黑工业大学（TU Munich）深度学习导论课程的第一讲，介绍课程的整体结构、评估方式和核心内容概览。

## 课程基本信息

| 项目 | 内容 |
|------|------|
| **课程名称** | Introduction to Deep Learning (I2DL) |
| **授课机构** | TU Munich (慕尼黑工业大学) |
| **语言** | 英语 |
| **学分** | 8 CP |
| **评估** | 笔试 + 编程作业 (60% Python, 40% 理论) |

## 课程结构

### 理论部分 (每周2小时)
1. 机器学习基础回顾
2. 神经网络基础
3. 卷积神经网络 (CNN)
4. 循环神经网络 (RNN)
5. Transformers & Attention
6. 自编码器 & 生成模型
7. 图神经网络
8. 强化学习基础

### 实践部分 (每周2小时)
- PyTorch 深度学习框架
- Colab/Jupyter Notebook 环境
- 8个编程作业 (占总成绩60%)

## 前置要求

- 线性代数基础
- 概率论基础
- Python 编程能力
- 机器学习基本概念
