# AMD：AI芯片暗战之王

## 核心摘要

本文深入分析AMD的投资价值，从游戏机芯片霸主到AI芯片暗战者的战略转型，聚焦苏姿丰的十年翻身仗、GPU与英伟达的竞争态势、以及Xilinx收购带来的FPGA战略优势。

## 关键信息

| 维度 | 内容 |
|------|------|
| 当前股价 | ~$350 |
| 历史低点 | $2.5 (2014) |
| 涨幅 | 108倍 |
| 目标区间 | $320-$420 |

## 游戏机芯片帝国

AMD垄断游戏机市场：
- **PS5**：Zen 2 + RDNA 2, 10.28 TFLOPS
- **Xbox Series X**：52 CU, 12.15 TFLOPS
- **Steam Deck**：Van Gogh APU, 15W TDP
- **Switch 2**：传闻采用AMD RDNA 2

游戏机业务年营收约$62亿，但被市场低估。

## 苏姿丰的改革三板斧

1. **砍非核心**：专注高性能计算
2. **押注Zen**：2017年Ryzen追平Intel Core i7
3. **稳住客户**：游戏机定制芯片养活公司

2020年以$350亿收购Xilinx，进军FPGA领域。

## AMD的三张底牌

```
┌─────────────────────────────────────────┐
│               AMD 战略                    │
├─────────────┬─────────────┬──────────────┤
│    CPU      │    GPU      │     FPGA    │
│   (Zen)     │  (RDNA)     │  (Xilinx)   │
├─────────────┼─────────────┼──────────────┤
│ 游戏/数据中心 │ MI300X/MI400 │ 边缘AI推理  │
│  稳定收入    │  价格优势20-30%│ 低延迟灵活  │
└─────────────┴─────────────┴──────────────┘
```

### 底牌一：混合架构
- MI400首次整合CPU+GPU+FPGA
- 性能比单一芯片提升30%

### 底牌二：大客户绑定
- 微软Xbox、索尼PS唯一芯片供应商
- 特斯拉Model Y/Cybertruck用AMD处理器
- 亚马逊AWS合作

### 底牌三：AI推理市场
- 2025年推理市场$200亿，2028年翻倍
- FPGA适合低延迟、低功耗场景

## 竞争分析

| 对比 | AMD | 英伟达 |
|------|-----|--------|
| AI训练份额 | <20% | >80% |
| 价格优势 | 便宜20-30% | - |
| 软件生态 | ROCm起步 | CUDA城墙 |
| 差异化 | GPU+CPU+FPGA三合一 | 纯GPU路线 |

## 估值与仓位建议

**关键价位**
- 建议买入区间：$320-$340
- 第一目标：$380
- 止损位：$300
- 仓位上限：15%

**风险提示**
- AI投资周期降温
- CUDA生态粘性
- 英特尔FPGA整合追赶

## 核心观点

> AMD不是英伟达的替代品，而是AI芯片的另一个选择。暗战之王不一定要打赢正面战，但一定要在关键战场有牌。
