# AI工具站：从0到100的完整指南

## 核心摘要

本文是一份面向中国创业者的AI工具站出海教程，从需求挖掘到正式上线，手把手教你用最小成本打造一个面向全球用户的AI工具站。

**核心理念**：一个关键词 + 一个痛点 + 一个工具 + 一个结果 = 变现

## 八步完整流程

```
1. 挖掘需求
2. 写需求文档
3. 项目准备
4. 实现核心功能
5. 部署网站
6. 购买域名
7. 配置域名
8. 正式上线
```

---

## 一、挖掘需求的四种方法

### 1. 看榜单
- [Toolify.ai](https://www.toolify.ai/) - 2万+ AI工具，459个分类
- 看排名靠前的产品 → 已被市场验证

### 2. 关注热点
- 新AI模型/大事件出来后，相关工具站会爆火

### 3. SEO挖掘
**四个核心方法**：
| 方法 | 说明 |
|------|------|
| 词找站 | 用关键词在Google搜，看排名靠前的网站 |
| 站找词 | 找到竞品站，反查它靠哪些关键词拿流量 |
| 词找词 | 从一个关键词扩展相关词、长尾词、新词 |
| 站找站 | 从一个竞品找到更多同类网站 |

**示例搜索词**：
- AI background remover（去背景）
- AI detector（检测AI内容）
- AI humanizer（文章真人化）
- AI PPT maker（做PPT）

### 4. 监控sitemap
- 监控CrazyGames等大站的sitemap更新
- 从新增页面反推新词和新需求

## 二、MVP需求文档

一份合格的MVP文档需包含：

1. **产品定位** - 这个工具解决什么问题
2. **目标用户** - 谁会使用它
3. **用户痛点** - 用户为什么需要它
4. **核心功能** - 第一版必须实现什么
5. **暂不实现功能** - 先不做，防止跑偏
6. **页面结构** - 首页、输入区、结果区、CTA
7. **技术方案** - 前端、模型API、部署、数据存储
8. **MVP成功标准** - 能提交、能生成、能收录、有用户

## 五、核心思维模式

### MVP优先
- 第一版不追求完美
- 先跑通闭环：搜索流量 → 用户使用

### 验证后再迭代
- 有人用 → 继续迭代（登录、支付、会员）
- 没人用 → 换词、换方向

### 汇率差思维
- 做海外产品，收美元
- 开发成本在大陆，收益在国际
