# 美光MU：HBM周期下的存储寡头红利

## 核心论点

把美光当作传统周期股是最大误区。本轮AI驱动周期与历史周期有本质区别。

## 三大维度重构估值

### 1. DRAM vs NAND的本质差异

| 特性 | DRAM | NAND |
|------|------|------|
| 存储单元 | 电容器 | 浮栅晶体管 |
| 技术壁垒 | 极高（EUV必需） | 中等（堆叠设备） |
| 资本回报 | 高 | 低 |
| 美光占比 | ~70% | ~30% |

DRAM需要EUV光刻机，二线厂商难以追赶。NAND通过垂直堆叠扩容，门槛可控。

### 2. 寡头垄断的供给纪律

存储从数十家整合到三家：**三星、SK海力士、美光**

**HBM产能挤压效应**：
- Die Size Penalty：HBM占用面积是DDR5的2-2.5倍
- Yield Loss：任何一层良率问题整颗报废

**结论**：生产1片HBM = 消耗3-4片DDR5产能

只要HBM需求不崩，传统DRAM供给就被人为压缩。

### 3. 定价权从量转向价

```
历史逻辑：营收 = 位元增长 × ASP
本轮逻辑：位元仅中个位数增长，ASP大幅上行
```

HBM售价是标准DRAM数倍，通过长协锁定。

## 经营杠杆分析

```
固定成本结构（晶圆厂$150-200亿）:

ASP $100 → $120:
  新增$20几乎100%转化为营业利润
  
这就是周期上行期利润非线性爆发的根源。
```

## 周期投资的反常识法则

1. **DIO见底信号**：从~220天高位开始环比下降（≠回到100天才买）
2. **渠道双重确认**：美光库存↓ + 客户库存同步降至4-6周
3. **存货减值**：是管理层"洗财务"，不是灾难
4. **现金流先行**：FCF见底比利润见底早1-2季度

## 风险信号

三个触发减仓的条件（任一出现）：
1. 某云厂商暗示AI投资回报率不及预期
2. HBM现货价开始小幅松动
3. 台积电CoWoS扩张速度超过英伟达需求增速
