Project description

The new version of **Flix quadcopter** — v1. See [$ previous version v0 $](https://projecthub.arduino.cc/okalachev/flix-58fe43) . The project is dedicated for education and research.

Main features:

1. Built from scratch from general-purpose components.
	2. Very simple and clean Arduino source code.
	3. Precise simulation using Gazebo.
	4. Wi-Fi and MAVLink support.
	5. Wireless command line interface and analyzing.
	6. Textbook on flight control theory and practice.
	7. Planned: position control, autonomous flights, PCB.
