# I2DL 三线演进：各自解决的问题

## TL;DR

- **Lecture** 回答："深度学习系统要解决哪些核心问题？"
- **Tutorial** 回答："实现这些问题需要什么前置能力？"
- **Exercise** 回答："如何亲手把解决方案写成代码？"

## Lecture 演进：核心问题清单

```
起点：什么是学习？
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│ L01-L02: 如何让机器从数据中找规律？                          │
│   答案：线性模型 + 损失函数 + 优化                              │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│ L03: 如何突破线性限制，学到复杂模式？                          │
│   答案：激活函数 + 隐藏层 + MLP                                │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│ L04-L05: 多层网络如何高效计算和训练？                          │
│   答案：反向传播 + 链式法则 + Mini-batch + Adam                │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│ L06: 如何让模型真正 work 而不是调参玄学？                       │
│   答案：系统化训练流程 + Debug 方法论                          │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│ L07-L08: 如何防止欠/过拟合，让模型泛化？                        │

        ▼
```

| 组件 | 解决的元问题 | 回答方式 |
