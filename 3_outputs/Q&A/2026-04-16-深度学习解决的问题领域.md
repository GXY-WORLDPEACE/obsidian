# 深度学习解决的问题领域

## TL;DR

深度学习主要解决 4 大类问题：**感知理解、序列生成、结构化数据、决策控制**，对应 CV、NLP、推荐、强化学习等领域。

---

## 问题领域总览

```
深度学习解决的问题
│
├── 1. 感知理解：让机器"看得懂、听得懂"
│   ├── 计算机视觉 (CV)
│   └── 自然语言处理 (NLP)
│
├── 2. 序列生成：让机器"能说会写"
│   ├── 文本生成
│   ├── 图像生成
│   └── 语音合成
│
├── 3. 结构化数据：让机器"处理非原始格式"
│   ├── 图数据 (GNN)
│   ├── 推荐系统
│   └── 时序预测
│
└── 4. 决策控制：让机器"自主决策"
    ├── 强化学习
    └── 自动驾驶/机器人
```

---

## 1. 感知理解：识别与理解

### 计算机视觉 (CV)

| 任务                | 输入   | 输出     | 典型模型                 |
| ----------------- | ---- | ------ | -------------------- |
| **图像分类**          | 图片   | 类别标签   | ResNet, EfficientNet |
| **目标检测**          | 图片   | 边界框+类别 | YOLO, Faster R-CNN   |
| **语义分割**          | 图片   | 像素级类别  | FCN, U-Net, DeepLab  |
| **人脸识别**          | 人脸图片 | 身份ID   | ArcFace, FaceNet     |
| **图像 captioning** | 图片   | 文字描述   | CLIP, BLIP           |
|                   |      |        |                      |

**核心架构**：CNN (L09) → 更深更高效 (L10) → 注意力增强

### 自然语言处理 (NLP)

| 任务       | 输入        | 输出     | 典型模型          |
| -------- | --------- | ------ | ------------- |
| **文本分类** | 文本        | 类别标签   | BERT, RoBERTa |
| **机器翻译** | 源语言文本     | 目标语言文本 | Transformer   |
| **问答系统** | 问题+文档     | 答案     | GPT, RAG      |
| **情感分析** | 评论文本      | 情感极性   | BERT          |
| **文本生成** | 提示/prompt | 生成文本   | GPT, LLaMA    |

**核心架构**：RNN (L11) → Transformer (L11) → 大语言模型 (L12)

## 2. 序列生成：创造新内容

### 生成模型家族

```
生成模型
├── 自回归模型
│   ├── PixelCNN (图像)
│   └── GPT 系列 (文本/LLM)
│
├── 变分自编码器 (VAE)
│   ├── 图像生成
│   └── 潜空间操纵
│
├── 生成对抗网络 (GAN)
│   ├── 图像生成 (StyleGAN)
│   ├── 人脸替换 (DeepFake)
│   └── 数据增强
│
└── 扩散模型 (Diffusion)
    ├── 图像生成 (DALL-E, Stable Diffusion)
    └── 音频生成
```

**课程对应**：L08 数据增强 → L12 VAE/GAN/LLM

---

## 3. 结构化数据：超越原始张量

### 图神经网络 (GNN)

| 应用 | 场景 |
|------|------|
| **社交网络** | 好友推荐、用户分析 |
| **知识图谱** | 实体关系推理 |
| **分子性质** | 药物发现 |
| **交通预测** | 路网流量 |

**核心思想**：邻居节点信息聚合

### 其他结构化任务

| 领域 | 任务 | 特点 |
|------|------|------|
| **推荐系统** | 商品/内容推荐 | 协同过滤、embedding |
| **时序预测** | 股价/天气预测 | LSTM, Transformer |
| **异常检测** | 欺诈/故障检测 | 自编码器重建误差 |

**课程对应**：L11 RNN → L12 GNN/时序

---

## 4. 决策控制：与环境交互

### 强化学习 (RL)

```
强化学习框架
┌─────────────────────────────────────┐
│  Agent (智能体)                      │
│    │                                 │
│    ├── 观察 State (s)               │
│    ├── 采取 Action (a)              │
│    └── 获得 Reward (r)               │
│              ↑                      │
│         Environment (环境)           │
└─────────────────────────────────────┘
```

| 应用 | 说明 |
|------|------|
| **游戏 AI** | AlphaGo, OpenAI Five |
| **机器人控制** | 机械臂、行走机器人 |
| **自动驾驶** | 路径规划、决策 |
| **资源调度** | 数据中心节能 |

**核心挑战**：探索-利用权衡、长期奖励

## 问题类型分类

```
按输入输出分类
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

感知类 (输入→标签)
├── 分类：这是猫还是狗？
├── 检测：猫在哪里？
└── 分割：猫的像素在哪里？

生成类 (输入→新内容)
├── 文本续写
├── 图像生成
└── 语音合成

序列类 (序列→序列)
├── 翻译：中文→英文
├── 语音识别：音频→文本
└── 文本摘要：长文→短文

决策类 (状态→动作)
├── 下棋走哪步
├── 机器人往哪走
└── 自动驾驶怎么转
```
