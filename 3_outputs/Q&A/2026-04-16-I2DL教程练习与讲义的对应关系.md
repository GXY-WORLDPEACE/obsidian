# I2DL Tutorial & Exercise 解析

## TL;DR

- **Tutorial**：为 Lecture 提供数学/编程预备知识，补齐前置技能
- **Exercise**：亲手实现 Lecture 中的核心算法，60% 成绩占比
- **Lecture**：理论框架与概念解释，"是什么/为什么"
- 三者分工：Tutorial 补基础 → Lecture 给理论 → Exercise 动手做

---

## Tutorial 解析

Tutorial 不是讲义的附属，而是**前置准备**，解决讲义假设你已会的技能缺口。

### Tutorial 列表与功能

| Tutorial | 主题 | 解决的问题 |
|----------|------|-----------|
| T02 | Math Recap | 线性代数复习：矩阵运算、导数、链式法则 |
| T03 | Data | Python 数据处理：NumPy、Pandas、可视化 |
| T04 | Simple Classifier | 最小可运行分类器：KNN、决策边界可视化 |
| T05 | Neural Networks | 从 T04 的传统 ML 过渡到 NN |
| T06 | Hyperparameter Tuning | 调参方法：Grid Search、Random Search、可视化 |
| T07 | PyTorch | 框架速成：张量、自动求导、nn.Module |
| T08 | Autoencoder | 自编码器概念与 PyTorch 实现预览 |
| T09 | CNN | 卷积层、Pooling、特征图可视化 |
| T10 | Semantic Segmentation | 像素级任务：FCN、U-Net |
| T11 | NLP & Transformers | Tokenization、Embedding、Attention |

### Tutorial 的本质功能

```
讲义假设你会的 ──────────────────────── Tutorial 补齐的
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
矩阵求导、链式法则 ←────────── T02 Math Recap
Python 科学计算 ←────────────── T03 Data
调参实验设计 ←─────────────── T06 Hyperparameter Tuning
PyTorch 框架 ←─────────────── T07 PyTorch (最重要)
```

## Exercise 解析

Exercise 是课程的**核心实践环节**，占 60% 成绩，11 个编程任务。

### Exercise 列表与对应关系

| Exercise | 主题 | 对应 Lecture | 核心任务 |
|----------|------|--------------|----------|
| E01 | Introduction | L01 | 环境配置、Colab、Jupyter 入门 |
| E03 | Dataset & Dataloader | L05-L06 | 数据加载、预处理、DataLoader |
| E04 | Simple Classifier | L02-L03 | 从零实现线性分类器、MSE Loss、SGD |
| E05 | Neural Networks | L03-L04 | MLP、激活函数、反向传播 |
| E06 | CNN | L05-L06 | 实现卷积层、训练 CNN |
| E07 | Training | L06 | 训练流程、TensorBoard、Debug |
| E08 | Regularization | L08 | Dropout、Data Augmentation |
| E09 | CNN Architectures | L09-L10 | ResNet 实现、迁移学习 |
| E10 | Semantic Seg. | L10 | FCN、U-Net |
| E11 | Transformers | L11 | Attention、Multi-Head、Positional Encoding |

### Exercise 的设计逻辑

```
阶段一：底层实现 (E04-E05)
─────────────────────────────────────
从零手写，不调用高级 API
目的：理解每一行代码背后的数学
├── 手动计算梯度
├── 手动实现激活函数
└── 手动实现反向传播

阶段二：框架使用 (E03-E06)
─────────────────────────────────────
用 PyTorch API 重写
目的：掌握工业界标准工具
├── DataLoader
├── nn.Module
└── optim.SGD

阶段三：完整训练 (E07)
─────────────────────────────────────
端到端训练流程
目的：学会调试和监控
├── TensorBoard
├── Early Stopping
└── 超参管理

阶段四：高级任务 (E08-E11)
─────────────────────────────────────
完整项目
目的：独立完成 DL 任务
├── 数据增强
├── 迁移学习
└── Transformer
```

## 总结

| 组件 | 回答的问题 | 形式 |
|------|-----------|------|
| **Lecture** | 这个技术是什么？为什么有效？ | PPT 讲解 |
| **Tutorial** | 实现这个技术需要什么前置技能？ | Notebook + 练习 |
| **Exercise** | 如何亲手把理论变成可运行的代码？ | 编程作业 + 评分 |

**关键洞察**：Tutorial 是连接 Lecture 和 Exercise 的桥梁。Lecture 讲原理时假设你有数学/框架基础，Tutorial 在讲义前把这些基础补齐；Exercise 在讲义后让你亲手实现核心算法。
