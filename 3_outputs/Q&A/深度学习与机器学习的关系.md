# 深度学习与机器学习的关系

## TL;DR

**深度学习 (DL) 是机器学习 (ML) 的一个子领域**，两者是包含关系而非并列关系。

```
人工智能 (AI)
  └── 机器学习 (ML)
        └── 深度学习 (DL)
              └── 神经网络 (Neural Network)
```

---

## 层级关系

| 层级 | 定义 | 特点 |
|------|------|------|
| AI | 使机器具有人类智能 | 范围最广 |
| ML | 从数据中自动学习 | 基于统计学 |
| DL | 多层神经网络 | 端到端学习 |

---

## 核心区别

| 维度 | 传统机器学习 | 深度学习 |
|------|-------------|----------|
| **特征工程** | 人工设计特征 | 自动学习特征 |
| **模型复杂度** | 简单（SVM, 决策树） | 深层网络 |
| **数据需求** | 较小（千级） | 较大（万级+） |
| **计算资源** | CPU 即可 | GPU/TPU |
| **可解释性** | 较高 | 较低 |

---

## 典型算法

### 传统机器学习
- 线性回归 / 逻辑回归
- 决策树 / 随机森林
- 支持向量机 (SVM)
- K近邻 (KNN)
- 聚类 (K-Means)

### 深度学习
- 全连接神经网络 (FFNN)
- 卷积神经网络 (CNN)
- 循环神经网络 (RNN/LSTM)
- Transformer
- 生成模型 (GAN, Diffusion)

---

## 选择判断

```
数据量小 (< 10K)?
├─ 是 → 传统 ML（特征工程重要）
└─ 否 → 数据有空间/序列结构?
         ├─ 图像 → CNN
         ├─ 序列 → RNN/Transformer
         └─ 表格/小数据 → 传统 ML / 轻量 DL
```
