# 第三章节介绍的内容是什么

## TL;DR

Lecture 3 是"神经网络入门"，从线性回归出发，逐步引入非线性激活函数，讲解神经网络的基本结构、计算图、损失函数和梯度下降。

## 结论

### 课程结构（共 62 页）

| 页码 | 主题 | 内容 |
|------|------|------|
| 1-10 | 从线性到非线性 | 线性回归 → 逻辑回归 → 线性分类器局限 |
| 11-27 | 神经网络结构 | 多层感知机、激活函数、生物神经元类比 |

### 核心内容

#### 1. 为什么需要非线性？ (Page 9-10)

> "Linear Score Functions? — Logistic Regression Linear Separation Impossible!"

线性分类器无法解决 XOR 等非线性可分问题。

#### 2. 神经网络的数学形式 (Page 11)

```
2层网络: f = W₂ · max(0, W₁·x)
3层网络: f = W₃ · max(0, W₂ · max(0, W₁·x))
```

#### 3. 激活函数 (Page 20)

| 函数 | 公式 |
|------|------|
| Sigmoid | σ(x) = 1/(1+e⁻ˣ) |
| Tanh | tanh(x) |
| **ReLU** | max(0, x) |
| Leaky ReLU | max(0.1x, x) |
| Maxout | max(w₁ᵀx+b₁, w₂ᵀx+b₂) |
| ELU | x>0 ? x : α(eˣ-1) |

#### 4. 计算图 (Page 29-37)

> "Computational Graphs — Matrix operations are represented as compute nodes"
> - 节点：变量或操作 (+, -, *, /, log, exp)
> - 边：数据流向

**前向传播**：计算输出
**反向传播**：计算梯度

#### 5. 损失函数 (Page 43-45)

| 类型                   | 公式                           | 用途      |     |     |
| -------------------- | ---------------------------- | ------- | --- | --- |
| L1 Loss              | (1/n)Σ                       | yᵢ - ŷᵢ |     | 回归  |
| MSE                  | (1/n)Σ                       | yᵢ - ŷᵢ | ²   | 回归  |
| Binary Cross-Entropy | -[y·log(ŷ) + (1-y)·log(1-ŷ)] | 二分类     |     |     |
| Cross-Entropy        | -Σ yₖ·log(ŷₖ)                | 多分类     |     |     |

#### 6. 梯度下降 (Page 53)

```
θ_{t+1} = θ_t - α · ∇_θ L(y, f_θ(x))
```

### 课程总结 (Page 61)

> 1. Neural Networks are computational graphs
> 2. Goal: for a given train set, find optimal weights
> 3. Optimization is done using gradient-based solvers
> 4. Gradients are computed via backpropagation
