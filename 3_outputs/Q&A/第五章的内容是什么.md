### 核心内容

#### 1. 随机梯度下降 SGD (Page 26-32)

> "If we have n training samples, we need to compute the gradient for all of them which is O(n)"
> "The expectation can be approximated with a small subset of the data"

**Mini-batch**：
```
选择训练集的一个小子集 m << n
B_i = {x₁,y₁, x₂,y₂, ..., x_m,y_m}
```

| 方法 | 样本数 | 复杂度 |
|------|--------|--------|
| Batch GD | n | O(n) |
| SGD | 1 | O(1) |
| Mini-batch | m (如32/64/128) | O(m) |

#### 2. Momentum (Page 33-38)

> "We're making many steps back and forth along this dimension. Would love to track that this is averaging out over time."

```
v_{k+1} = β · v_k + (1-β) · ∇L(θ)
θ_{k+1} = θ_k - α · v_{k+1}
```

**作用**：
- 加速收敛
- 减少震荡
- β 通常取 0.9

**Nesterov Momentum**：先看一步的梯度方向，比标准动量更激进。

#### 3. RMSProp (Page 39-42)

> "RMSProp divides the learning rate by an exponentially-decaying average of squared gradients."

```
s_{k+1} = β · s_k + (1-β) · (∇L)²
θ_{k+1} = θ_k - α · ∇L / (√s_{k+1} + ε)
```

**作用**：自适应学习率，对不同参数用不同学习率。

#### 4. Adam (Page 43-45)

> "Combine Momentum and RMSProp"

```
m_{k+1} = β₁ · m_k + (1-β₁) · ∇L      # 一阶矩（Momentum）
v_{k+1} = β₂ · v_k + (1-β₂) · (∇L)²   # 二阶矩（RMSProp）
θ_{k+1} = θ_k - α · m_{k+1} / (√v_{k+1} + ε)
```

**默认参数**：β₁=0.9, β₂=0.999, ε=10⁻⁸

#### 5. 其他优化器 (Page 46-59)

| 优化器 | 特点 |
|--------|------|
| AdaGrad | 适合稀疏数据 |
| Adadelta | 改进 AdaGrad |
| AdaMax | Adam 变体 |
| Newton | 需要 Hessian，计算量大 |
| L-BFGS | 近似 Hessian |
| Gauss-Newton | 近似 Hessian |
| LM (Levenberg-Marquardt) | 非线性最小二乘 |

#### 6. 如何选择优化器 (Page 60)

> "Standard: Adam"
> "Fallback option: SGD with momentum"
> "Newton, L-BFGS, GN, LM only if you can do full batch updates"

| 场景 | 推荐 |
|------|------|
| 默认 | Adam |
| 图像分类 | SGD + Momentum |
| 大 batch | L-BFGS / Newton |
