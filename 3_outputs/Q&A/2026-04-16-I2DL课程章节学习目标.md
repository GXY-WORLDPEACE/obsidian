# I2DL 课程章节学习目标

## TL;DR

12 讲的目标：从零开始，最终让你具备独立完成深度学习项目的能力。

```
L01-L04 基础理论 → L05-L08 工程实践 → L09-L11 专用架构 → L12 前沿扩展
   "是什么"           "怎么做"               "用什么"              "还能做什么"
```

---

## 章节学习目标

### L01 · 课程导论

**目标**：建立课程全局观，了解深度学习全貌

```
你将学会：
├── 深度学习的应用领域（CV、NLP、RL、生成模型）
├── 课程结构与评估方式
├── 前置知识要求
└── 工具生态（PyTorch）
```

---

### L02 · 线性回归

**目标**：理解最简单的"学习"形式

```
你将学会：
├── 什么是"学习"：从数据中找规律
├── 线性模型：ŷ = wx + b
├── 损失函数：MSE（均方误差）
├── 如何用数学求解：闭式解 w* = (XᵀX)⁻¹Xᵀy
└── 为什么线性模型不够用（引入 L03）
```

---

### L03 · 神经网络基础

**目标**：理解非线性表示从何而来

```
你将学会：
├── 感知机：单层神经网络的原理
├── 激活函数：ReLU、Sigmoid、Tanh
├── 多层感知机 (MLP)：隐藏层的意义
├── 通用近似定理：神经网络能近似任意函数
└── 层次化表示：从低级到高级特征
```

---

### L04 · 反向传播与优化

**目标**：理解神经网络是如何"学会"的

```
你将学会：
├── 链式法则：复合函数求导
├── 反向传播：高效计算梯度的算法
├── 计算图：分解网络为基本操作
├── 梯度下降：w := w - α∇L
├── SGD、Momentum、Adam 优化器
└── 梯度消失/爆炸问题
```

---

### L05 · 规模化优化

**目标**：掌握大规模训练的工程技巧

```
你将学会：
├── Mini-batch SGD：效率与精度的平衡
├── 学习率调度：Step Decay、Cosine Annealing
├── Batch Normalization：稳定训练
├── Adam 优化器：自适应学习率
├── 权重初始化：Xavier、Kaiming
└── 如何高效利用 GPU
```

---

### L06 · 训练实践

**目标**：让模型真正 work 而不是调参玄学

```
你将学会：
├── 数据划分：训练集/验证集/测试集
├── 超参数调优：学习率、batch size、网络结构
├── Debug 方法：梯度检查、过拟合检查
├── 过拟合 vs 欠拟合的判断
├── 训练监控：TensorBoard
└── 工程最佳实践
```

---

### L07 · 损失函数与激活函数

**目标**：根据任务正确配置输出层

```
你将学会：
├── 激活函数对比：Sigmoid、Softmax、ReLU
├── 分类任务：Softmax + Cross-Entropy
├── 回归任务：Linear + MSE
├── 损失函数选择原则
├── Label Smoothing：防止过自信
└── 输出层设计规范
```

---

### L08 · 数据增强与正则化

**目标**：提高模型的泛化能力

```
你将学会：
├── 过拟合的成因与判断
├── 数据增强：翻转、裁剪、MixUp、Cutmix
├── Dropout：随机失活神经元
├── L1/L2 正则化：权重衰减
├── Early Stopping：早停策略
├── Label Smoothing
└── 泛化理论与实践
```

---

### L09 · 卷积神经网络

**目标**：掌握图像处理的专用架构

```
你将学会：
├── 卷积操作：局部连接 + 权重共享
├── 卷积层参数：kernel、stride、padding
├── 池化层：Max Pool、Avg Pool
├── CNN 架构演进：LeNet → AlexNet → VGG
├── 特征层次：边缘 → 纹理 → 物体
├── 感受野：理解特征提取范围
└── 用 CNN 做图像分类
```

---

### L10 · 现代架构

**目标**：掌握更深更强网络的设计原理

```
你将学会：
├── ResNet：残差连接解决梯度消失
├── 跳跃连接：y = F(x) + x
├── EfficientNet：复合缩放策略
├── 注意力机制入门：SE-Net
├── Depthwise Separable Conv
├── 迁移学习：用预训练模型
└── 如何设计高效网络
```

---

### L11 · RNN 与 Transformer

**目标**：掌握序列数据的建模方法

```
你将学会：
├── RNN：处理序列数据
├── LSTM/GRU：解决长期依赖
├── Self-Attention：Query-Key-Value
├── Transformer：注意力机制革命
├── Multi-Head Attention：多角度关注
├── Positional Encoding：位置信息
├── Encoder-Decoder 架构
└── RNN vs Transformer 的权衡
```

---

### L12 · 前沿话题

**目标**：了解深度学习的能力边界与前沿

```
你将学会：
├── 生成模型：VAE、GAN
├── 图神经网络 (GNN)：图数据建模
├── 自监督学习：对比学习、掩码重建
├── 大语言模型 (LLM)：GPT、BERT
├── RLHF：人类反馈强化学习
├── Scaling Laws：规模定律
└── 深度学习的未来方向
```
