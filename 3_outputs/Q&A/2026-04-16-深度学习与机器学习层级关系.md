# 深度学习与机器学习层级关系

## TL;DR
AI ⊇ ML ⊇ DL，深度学习是机器学习的一个子领域，核心区别在于神经网络的深度和特征学习方式。

## 结论
三者是包含与被包含的层级关系：

```
AI（人工智能）
 └─ Machine Learning（机器学习）
     └─ Deep Learning（深度学习）
         ├─ MLP / CNN / RNN / Transformer
```

**核心区别：**
| 维度 | 机器学习 | 深度学习 |
|------|----------|----------|
| 特征处理 | 手工特征工程 | 自动层次化特征学习 |
| 模型复杂度 | 较浅（支持向量机、决策树等） | 深层神经网络（多隐藏层） |
| 数据依赖 | 中小规模数据 | 需要大规模数据 |
| 计算资源 | CPU 即可 | 需要 GPU/TPU |

## 证据
- [[2_wiki/concepts/Machine Learning]]：「Deep Learning 是 Machine Learning 的一个子领域，当 Neural Networks 的隐藏层数量足够深时，被称为深度学习」
- [[2_wiki/concepts/Deep Learning]]：「深度学习是 Machine Learning 的一个子领域，使用具有多个隐藏层的人工神经网络来自动学习数据的层次化表示」
