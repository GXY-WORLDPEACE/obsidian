# 卷积神经网络是什么

## TL;DR

卷积神经网络 (CNN) 是一种专门处理图像的神经网络，通过卷积操作提取空间特征，比全连接层更高效。

## 结论

### 1. 为什么不用全连接层处理图像？

| 问题 | 说明 |
|------|------|
| 参数爆炸 | 32×32×3 → 第一个 FC 层需要 1500+ 权重 |
| 丢失空间结构 | FC 层忽略像素位置关系 |
| 过拟合 | 参数量大，泛化能力差 |

### 2. 卷积操作是什么？

卷积 = 在图像上"滑动"滤波器，计算点积：

```
输入:  4 3 2    滤波器:  1/3 1/3 1/3
      1 0 3  ←───────────────→ 点积 = 加权和
      2 0 1
```

**每个滤波器捕获不同特征**：
- 水平边缘
- 垂直边缘
- 圆形
- 方形

### 3. 卷积层参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **Kernel Size** | 滤波器大小 | 3×3, 5×5 |
| **Stride** | 滑动步长 | 1, 2 |
| **Padding** | 边缘填充 | 0, 1 |
| **Depth** | 滤波器数量 | 32, 64, 128 |

### 4. 输出尺寸公式

```
Output = floor((N + 2P - F) / S + 1)
```

| 符号 | 含义 |
|------|------|
| N | 输入尺寸 |
| P | Padding |
| F | Kernel size |
| S | Stride |

### 5. 池化层 (Pooling)

- **Max Pooling**: 取窗口最大值（最常用）
- **Average Pooling**: 取窗口平均值

作用：减少尺寸、扩大感受野、提供平移不变性

### 6. 感受野 (Receptive Field)

输出特征图上一个像素对应输入图像的区域大小：

```
7×7 输入 → 3×3 卷积 → 输出 1 个像素
                         感受野 = 3×3
```

## 证据

### 全连接层问题 (Page 3-7)

> "Problems using FC Layers on Images"
> - 小图像 (5×5×3): 75 个权重
> - 正常图像 (32×32×3 → 1000 神经元层): 参数量巨大

### 卷积操作 (Page 16-31)

> "What are Convolutions?"
> - 滤波器滑动计算点积
> - 不同滤波器捕获不同图像特征

### RGB 图像卷积 (Page 36)

> "Images have depth: e.g. RGB -> 3 channels"
> - Convolve filter with image
> - i.e., 'slide' over it and: apply filter at each location, dot products

### 池化层 (Page 71-76)

> "Pooling Layer"
> - Input: W_in × H_in × D_in
> - Output: W_out × H_out × D_out
> - W_out = (W_in - F) / S + 1

### 感受野 (Page 81-86)

> "Receptive field: Spatial extent of the connectivity of a convolutional filter"
> - 7×7 input, 3×3 output
> - 3×3 receptive field = 1 output pixel is connected to
