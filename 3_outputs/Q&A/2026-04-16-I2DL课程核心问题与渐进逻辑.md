# I2DL 课程核心问题与渐进逻辑

## TL;DR
课程围绕一个核心问题展开：**如何构建能够从数据中自动学习的智能系统？**

渐进路线：从单层到多层 → 从线性到非线性 → 从训练到泛化 → 从通用到专用架构

---

## 每讲核心问题

| 讲次      | 核心问题                    | 回答要点                                                    |
| ------- | ----------------------- | ------------------------------------------------------- |
| **L01** | 课程是什么？要学什么？             | ML 基础框架、NN 核心思想、工具 PyTorch                              |
| **L02** | **最简单的学习系统是怎样的？**       | 线性回归 → 输入加权和 + MSE 损失 = 可学习的模型                          |
| **L03** | **如何让模型学到非线性模式？**       | 加激活函数 → 加隐藏层 → MLP → 通用近似定理                             |
| **L04** | **多层网络如何计算梯度并学习？**      | 链式法则 → 反向传播 → SGD/Momentum/Adam                         |
| **L05** | **如何高效训练大规模网络？**        | Mini-batch → 学习率调度 → BatchNorm → 自适应优化                  |
| **L06** | **如何让模型真正work而不是调参玄学？** | 数据划分 → 超参搜索 → Debug 策略 → 工程最佳实践                         |
| **L07** | **输出层应该怎么设计？**          | 激活函数配损失函数：Sigmoid+CE、Softmax+CE、Linear+MSE              |
| **L08** | **如何防止过拟合？**            | 数据增强 → Dropout/L1/L2 → Early Stopping → Label Smoothing |
| **L09** | **图像数据用什么结构处理？**        | 卷积 → 权重共享 → 层次化特征 → LeNet/AlexNet/VGG                   |
| **L10** | **如何训练更深更高效的网络？**       | 残差连接 → 复合缩放 → 注意力机制 → EfficientNet                      |
| **L11** | **序列数据如何建模？长距离依赖怎么办？**  | RNN/LSTM/GRU → Self-Attention → Transformer 革命          |
| **L12** | **DL 前沿在哪里？**           | 生成模型(VAE/GAN) → 图数据(GNN) → 自监督 → LLM                    |

## 三条主线

### 1. 表达能力线
```
线性 (L02) → 非线性 (L03) → 更深 (L09-L10-L11)
```
从能学直线到能学任意函数

### 2. 训练能力线
```
闭式解 (L02) → 反向传播 (L04) → 大规模训练 (L05) → 调参 (L06)
```
从数学求解到工程实践

### 3. 泛化能力线
```
过拟合风险 → 正则化 (L08) → 数据增强 (L08) → 测试集评估
```
从能学到学得好
